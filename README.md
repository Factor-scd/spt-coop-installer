# SPT Co-op Installer

1. Put `setup-spt.ps1` and `run-setup.bat` in the same folder.
2. Double-click **`run-setup.bat`** -> click **Yes** on the UAC prompt *(if Windows warns "Windows protected your PC": More info -> Run anyway)*.
3. Press Enter for the default install path (`C:\SPT`) or type your own.
4. Wait for install -> **`ALL DONE`** -> run `SPT_Runtime\SPT.Launcher.exe`, pick **Matt Co-op**.
